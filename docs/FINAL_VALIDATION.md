# Проверка основного этапа

Дата: 5 октября 2026 года. Машинные результаты:
[final-validation.json](final-validation.json). Первичная локальная проверка:
[LOCAL_VALIDATION.md](LOCAL_VALIDATION.md).

В текущем этапе добавлены основное исследование, сохранённые нейросетевые
прототипы, методология и сверка с ИУП. Исправлена потеря градиента при обрезке
отрицательных выходов; старые checkpoint читаются с прежним преобразованием.
Inference выполняется батчами. Основная выборка отбирается только по train
и исключает товары предварительного исследования. Загрузчик использует seed
конкретного запуска. Скрипт запуска задаёт доступный временный каталог.

Проверено:

- 54 Python-теста, без пропусков. Включены градиенты трёх архитектур,
  совместимость старых весов, порядок и масштаб квантилей, воспроизводимость
  загрузчика, отсутствие зависимости выбора SKU от будущей активности,
  исключение товаров без train-истории и возобновление замороженных заданий.
- Синтаксис Python и JavaScript, запуск CLI и PHP Pint.
- Совместимость Composer lock с PHP 8.2, требования платформы, pip check.
  Composer audit не обнаружил опубликованных уязвимостей.

Первоначально все 39 PHP-тестов прошли с 242 assertions, также прошли HTTP,
Excel, PDF/PPTX и браузерные проверки. В повторном запуске текущего ограниченного
окружения 36 тестов прошли, три завершились ошибкой чтения Excel: PHP
`is_readable()` возвращает false для существующих файлов, хотя `file_get_contents()`
их читает. Ошибка воспроизводится на PHP 8.2.34 и 8.4.14. Стандартный bootstrap
PHPUnit блокируется тем же условием; повторный прогон использовал
`--no-configuration` с тестовыми переменными из `phpunit.xml`.
Проверки читаемости в production-коде и библиотеках не отключались.

Это ограничение повторной локальной проверки. Штатный прогон в GitHub Actions
на Ubuntu / PHP 8.2 прошёл: 39 тестов, 242 assertions. Результат CI подтверждает
работоспособность тестов в этом окружении; ограничение локального PHP сохраняется.

Docker локально не проверен: engine не доступен, WSL не установлен.
Сборка образа в CI прошла; запуск контейнера в production этим не подтверждается.

## Проверка публикации

Изменения опубликованы в [PR №7](https://github.com/mi6gin/luch-magistratura/pull/7).
[CI для исходного коммита da5e816](https://github.com/mi6gin/luch-magistratura/actions/runs/37274640683)
завершился успешно: все шесть задач прошли. Проверены PHP-тесты и Pint,
54 Python-теста на Linux и Windows без пропусков, синтаксис JavaScript,
аудит зависимостей и сборка Docker. На обеих ОС проверены 36 SHA256 артефактов
исследования, 25 200 строк прогнозов и выполнение трёх сохранённых прототипов.
Этот отчёт добавляет результаты CI к проверенной версии; новые изменения
документации также проходят CI перед слиянием.

## Воспроизводимое исследование

Основной отчёт: [research/full-study/report.md](research/full-study/report.md).
Протокол: [research/full-study/protocol.json](research/full-study/protocol.json).
Структура запуска: 24 validation-конфигурации, девять финальных запусков,
36 сценарных запусков и 18 независимых замеров масштабирования.
Отдельно сравниваются пять baseline при общей истории 90 дней.

Число запусков не заменяет оценку их качества. Низкое покрытие интервалов,
недопрогноз, редкий спрос и пределы переноса на новый склад описаны в отчёте.
Исследовательские веса UCI не публикуются как production-модель предприятия.

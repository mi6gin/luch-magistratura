Проверено 5 октября 2026 года на Windows 11. Полный Git-клон проекта находится
в `outputs/luch-magistratura` в папке текущей задачи Codex. Исходный commit:

## Запуск на этом компьютере

Зависимости уже установлены: portable PHP 8.2.34, Composer, Python 3.12.14,
CPU PyTorch 2.14.1, Laravel и библиотеки отчётов. Рабочая SQLite создана из
демонстрационной базы. Локальный пароль администратора сгенерирован отдельно
и хранится только в `.env`, вместе с адресом `RAYVENTORY_ADMIN_EMAIL`.

Из корня проекта в PowerShell:

```powershell
./scripts/start-local.ps1 -Mode web
```

Откройте [приложение](http://127.0.0.1:8765). При занятом порте можно указать
другой: `-Port 8766`. Для обработки фонового обучения откройте второй терминал:

```powershell
./scripts/start-local.ps1 -Mode worker
```

Все основные автоматические проверки:

```powershell
./scripts/start-local.ps1 -Mode verify
```

Скрипт использует локальный PHP из `.tools` и Python из `.venv-ml`; эти каталоги,
`vendor`, `.env`, рабочая база и необработанные данные исключены из Git.
При переносе на другой компьютер зависимости нужно установить по README.

## Исправленные ошибки

1. **Windows-запуск исследований.** Убрана обязательная зависимость от Unix-модуля
   `resource`; измерение памяти на Windows выполняется через native API.
   JSON CLI принудительно использует UTF-8 даже при системной кодировке cp1251.
   SQLite-соединения закрываются, пути с пробелами и Unicode поддерживаются.
2. **Разделение данных.** Подбор конфигураций оценивает validation, не строит
   reserved test и отмечает это в результатах. Нестандартные временные границы
   manifest сохраняются. Validation-кандидаты не могут пройти production-gate.
   После tuning независимую итоговую оценку нужно проводить один раз с `folds=1`.
3. **Обработка исходных продаж.** M5-цены заполняются только из прошлого.
   Локальные/Excel-наборы сохраняют известный stockout и неизвестную доступность
   отдельно. Целевые окна с известным stockout исключаются; это оценка наблюдаемых
   продаж, а не восстановленного скрытого спроса. Старые processed-наборы следует
   подготовить заново.
4. **Прогноз и оценка активной модели.** Роутеры сохраняют влияние промо, цены,
   тренда и сезонности. Для неизвестного класса спроса используется медианный
   fallback. Backtesting оценивает фактически активную модель и корректно называет
   fallback. Восстановление прошлых продаж не использует будущий holdout;
   исключение цензурированных наблюдений не сдвигает даты прогнозов.
5. **Поставки.** Сохранены даты отдельных поставок. Остаток увеличивается в дату
   прибытия; поздние и недатированные поставки не скрывают ближайший дефицит
   и не уменьшают необходимый заказ на период lead time.
6. **Laravel ↔ Python.** Пустые overrides передаются как JSON-объект, поэтому
   симуляция с параметрами по умолчанию больше не возвращает 502.
7. **Вход пользователя филиала.** После входа выбирается первый доступный
   активный филиал пользователя. Ранее пользователь только филиала №2 получал
   403 на главной странице. Явное обращение к чужому филиалу остаётся запрещено.
8. **Окружение и отчёты.** Composer lock пересобран для заявленного PHP 8.2.
   Добавлены Windows-команды запуска, единые окончания строк PHP, полные
   ML-проверки для Windows/Linux в CI. Интерфейс и исследовательский отчёт
   различают validation/test и недоступные измерения памяти.
9. **Фоновое обучение.** Готовность учитывает минимум истории для трёх окон
   оценки, количество фактических наблюдений и известные stockout в test.
   Задача отправляется в настоящую database-очередь. Период повторной выдачи
   задания увеличен до 3660 секунд, сверх timeout обучения 3600 секунд.

## Что ещё требуется по ИУП

Исправления делают исследовательский контур работоспособным и устраняют
обнаруженные ошибки методики. Для итоговой работы нужны более крупные выборки,
обоснованный подбор параметров с отдельным финальным test, достаточное число
эпох и исследование устойчивости выводов. Измерения памяти в текущем стенде
являются максимумами за жизнь общего процесса, а не независимыми пиками моделей.

В UCI отсутствуют сведения о доступности товара и промо. Сценарии синтетические;
нейросети используют исторические признаки и пока не принимают будущий
промокалендарь как отдельный известный вход. Production использует baseline
или локальный роутер; нейросети остаются исследовательскими прототипами.

Текст глав, публикации, практика и документы для защиты требуют отдельного
подтверждения. Проверка и исправление кода сами по себе не закрывают все пункты ИУП.

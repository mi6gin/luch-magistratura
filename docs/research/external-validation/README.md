# Внешняя проверка прогнозов и последствий для запасов

Фактический расчёт от 01.11.2026: 60 продовольственных SKU M5 (Walmart, CA_1), девять обучений LSTM/GRU/Transformer v3, четыре базовых метода, 12 сценариев пополнения. Полный русский разбор: [REPORT_RU.md](REPORT_RU.md). Протокол задан до оценки теста; это локальная фиксация, а не публичная предварительная регистрация.

Transformer: WAPE **65,8545%**, сезонный наивный: **85,7545%**. В основном сценарии L3/R7/S0 их удовлетворённый объём составляет соответственно **69,0878%** и **82,3024%**, средний остаток — **5,0223** и **8,0283** единицы на SKU. Меньшая ошибка медианного прогноза не доказывает лучшую закупку: в данном сравнении нейросеть уменьшает запас ценой большего дефицита. Эти результаты не являются основанием автоматически включать модель в рабочем магазине.

## Что сохранено

- `protocol.json`: правила отбора, календарь, гиперпараметры, сценарии и ограничения.
- `cohort.csv.gz`: все 60 ежедневных рядов, отобранных по обучению, с календарными признаками и историческими ценами.
- `weights/{42,43,44}/`: девять checkpoint и полные журналы потерь. LSTM/GRU ограничены максимумом 40 эпох; три Transformer остановлены правилом patience.
- `forecast-test.csv.gz`: 23 520 строк (семь методов × 60 SKU × 56 дней), два неперекрывающихся 28-дневных блока.
- `daily-forecasts.npz`: причинные ежедневные прогнозы для имитации. Обновляется история, веса на тесте не дообучаются.
- `inventory-series.csv`: 5 040 траекторий (12 сценариев × семь методов × 60 SKU).
- `inventory-primary-daily.csv.gz`: 23 520 ежедневных движений основного сценария.
- `inventory-summary.csv`, `results.json`: все итоги, bootstrap-интервалы, параметры среды и контрольные суммы.
- `verification.json`: независимый пересчёт метрик из экспортов и проверка балансов.

`risk_cost_pct` в подробном JSON — условная асимметричная ошибка прогноза `(2×недопрогноз + перепрогноз)/продажи×100`, унаследованная из общего набора исследовательских метрик. Это не денежная стоимость и не измеренная экономия.

SNAP означает программу продовольственной помощи США, не скидку. Заполнение отсутствующих цен выполняется только из прошлого; признаки будущих акций и цен не подаются. Неизвестное наличие товара не объявляется наблюдавшимся наличием: исторические продажи используются как приближение спроса без искусственного восстановления потерь.

## Воспроизведение

Из корня проекта с установленными `requirements-ml.txt`:

```powershell
Invoke-WebRequest https://raw.githubusercontent.com/Nixtla/m5-forecasts/main/datasets/m5.zip -OutFile m5.zip
Get-FileHash m5.zip -Algorithm SHA256
python -m ml.research.external_validation --archive m5.zip --output storage/app/repeated-external-validation
python -m ml.research.verify_external_validation --report storage/app/repeated-external-validation
```

До расчёта сопоставьте SHA-256 загруженного архива со значением `sha256.source_archive` в опубликованном `results.json`. Изменившийся архив — другая версия данных. Повтор выполняйте в новом каталоге: имеющиеся checkpoint используются только при совпадении протокола и подготовленных данных. При изменении обучающего кода используйте новый каталог, чтобы не переиспользовать прежние веса.

Проверка сохранённого пакета без обучения:

```powershell
python -m ml.research.verify_external_validation --report docs/research/external-validation
python -m unittest discover -s ml/tests -p 'test_*.py'
```

Версии Python/PyTorch/NumPy/Pandas записаны в `results.json`. Начальные состояния заданы явно; полная побитовая повторяемость между разными платформами не заявляется. Архивное исследование `docs/research/full-study` использует UCI и параметризацию v2: его результаты не заменены и не смешаны с новым M5/v3.

## Границы вывода

Bootstrap выполняет 10 000 парных перевыборок SKU, сохраняя все дни одного товара вместе. Интервалы описательные и условны на один магазин и период; зависимость между товарами и неопределённость переноса на другие рынки не покрыты, поправка на множественные сравнения не выполнена. WAPE рассчитан на выбранных рядах без иерархии и весов M5; это не официальный соревновательный WRMSSE и не результат в рейтинге M5.

Имитация использует тот же `ml.purchasing.plan_order`, что и приложение; все методы получают одинаковую историческую информацию и параметры. Сроки поставки, исходные запасы, пересмотр и дополнительное покрытие заданы исследователем, а не извлечены из M5. Будущий спрос при заказе недоступен. Дефицит не переносится в задолженность, конечные заказы в пути не считаются поступившими. Обратная связь через искусственно цензурированные продажи отключена. Срок годности, списания, бюджет и денежные издержки не моделируются. Проверка не подтверждает внедрение или эффект в тенге в Караганде.

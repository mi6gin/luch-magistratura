# Rayventory

Веб-приложение для прогнозирования товарных запасов и планирования закупок.

- Учёт товаров и остатков по филиалам, импорт данных из Excel.
- Прогнозы, симуляция спроса и рекомендации по закупкам.
- Выгрузка отчётов в Excel, PDF и PowerPoint.
- Исследовательские прототипы LSTM, GRU и Transformer.

**Стек:** Laravel 12, Python, PyTorch, SQLite, JavaScript.
